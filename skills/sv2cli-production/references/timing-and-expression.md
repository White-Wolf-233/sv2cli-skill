# 实际时序、参考表演与力度

## 先定位失败层

“没唱齐”可能来自写谱时值错误、组局部/全局坐标混用、插件异步推理未完成、裁切拼接错位、辅音与元音时点不同，或参考表演的自由速度。检查现有音频是否确实来自当前工程；不要用旧音频判断新修改。

工程校验和谱面指纹只说明写谱数据，不能说明实际唱出的起音、收音、短字是否完整。混音中一个声部有声会掩盖另一个声部漏唱，应使用独立分轨；诊断起收音优先生成干声，避免把混响尾音当作音节。

## 音乐坐标

```sh
sv2cli time song.svp --at bar:53:1
sv2cli time song.svp --at q:7/2
sv2cli time song.svp --at s:24.5
sv2cli groups song.svp --track '#2'
sv2cli notes song.svp --track '#2' --start bar:53:1 --end bar:61:1
```

`bar:N:BEAT` 的小节、拍均为一基，拍按当前拍号分母计数（6/8 中一拍为八分音符）。`q:` 是四分音符数；`s:` 是工程时间轴秒数，含 startTimeSeconds。note 查询按区间重叠，recipe start/end 与 timing-check 按音符起点筛选，不混同两者。

recipe 的 start/end 可使用这些位置字符串；音符 values.onset、duration 仍是组内整数 blick。按组 UUID 表示组来源，`references:["引用UUID"]` 可明确某次引用；`groups` 输出给出两种 UUID。共享引用的局部编辑由 CLI 隔离，避免范围外跟着变。

## 音频检查与保守校正

```sh
sv2cli timing-check song.svp isolated.wav --track '#2' --start bar:53:1 --end bar:61:1 -o timing.json
```

输入必须是所选轨的独立 PCM16/24/32 WAV；这点无法从文件名自动证明，需核对渲染 manifest。默认假设 WAV 的 0 秒对应工程 0 秒。若片段从工程 20 秒开始，显式加 `--audio-origin 20`，不要因为缺少原点就推断延迟。

报告包含逐音符活动、可测入声的能量代理、可能的收声时间、超差项和未解决的连唱/重叠。`alignmentVerified` 始终为 false：这是诊断工具，不是音素强制对齐器。`valid:true` 仅表示该检查未发现活动缺失或可测入声超差，不代表所有音符边界已验证。

只有干声、谱面和短片段对照支持“同一段整体偏移”时，才使用显式移位：

```sh
sv2cli audio-shift song.svp isolated.wav --track '#2' --seconds -0.24 -o corrected.wav
```

负值提前，正值延后；数值必须来自当前片段实测，不照抄示例。工具不重采样、不改音高、不改 SVP。若提前会裁掉非静音开头，或位移使原本有声的音符窗口变空，拒绝输出。只接受 PCM16/24 写出；结果仍需复核入声、末字与休止，不自动覆盖原音频。

不要用单个换音点或谐波交叉决定整句提前/延后。几处看似一致的换音点也可能方向相反；必须检查第一字、末字和所有预期活动窗口。校正导致首音缺失时回退，不放宽全局检查。连续同音短字不能仅靠 F0 对齐；核对音素/字数与包络，必要时局部 ASR 提供辅助，ASR 也不是发声时间真值。

保留原始与校正音频和数值报告，生成同一时间轴的短 A/B。若需分别移动若干乐句，在临时副本中分句渲染，记录前滚、原点和拼接偏移，拼回分轨后再次检查；不要把一句补偿应用到整条轨。不要用硬门限截断未验证的辅音或混响尾音。

## 写谱时值与参考表演

确认谱面时值错误时，可使用 notes.update/shift 或 tempo.set，但遵循改谱授权。`--allow-score-changes` 允许时值编辑；`--score-lock` 继续阻止写谱变化。对自由速度、延长、呼喊等，先记录小节/拍到参考秒数的对应锚点，避免仅按整曲时长缩放。

没有自动参考录音强制对齐的能力；不要把活动检测说成已完成参考表演匹配。可自动完成工程核对、片段制作、活动检测和 A/B，剩余问题列出具体位置。

## 力度与声部主次

逐段核对 p/mp/mf/f、渐强渐弱、重音、气口、连线与主旋律交接。不要给所有声部套同一力度。主旋律转到低声部时，先确认旋律承接，再比较同时间段主唱/伴唱的实际能量；声库低音区可懂度不足不等于应升八度。

谱面力度、声库 loudness/tension、轨道增益和后期响度是不同控制层。先处理乐句形状与发声，再处理声部混音。参考能量比较不能证明某一声部的真实分离信号。呼喊/唱白单独做短片段试验，核对支持的模式、字数与气口；数值检查不能证明“像自然的人声呼喊”。
