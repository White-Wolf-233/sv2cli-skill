# 押韵与歌词写作

## 韵脚类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 平行押韵 | AABB 或 AAAA | 天边/眼前/相连/从前 |
| 交叉押韵 | ABAB | 行船/对岸/扬帆/靠岸 |
| 包孕押韵 | ABBA | 开头/收口/走透/开头 |
| 腰韵 | 句中押韵，非句尾 | 行到水穷处 |
| 内韵 | 句内重复音 | 碧水长流回故人 |

中文用十三辙或新诗韵部；英文用元音音素划分（如 ay, ee, oh, ar）。押韵按元音音素而非拼写判定。

## 押韵密度

- 主歌可稀押或不押，推动叙事。
- 导歌开始密押，建立期待。
- 副歌韵脚最密，强化记忆点。
- 桥段可换韵，提供新鲜感。

## 歌词与旋律配合

- 重音节落在强拍或次强拍。
- 长音（一字多音）放在乐句末尾或高潮处。
- 闭口元音（i, ü）天然偏亮，适合高音区或表达高亢。
- 开口元音（a, o）偏宽，适合乐句中段或叙事。
- 鼻音结尾（n, ng）适合延音收尾，听感柔和。

## 写词流程

1. 确定主题与情绪走向。
2. 划分段落，每段写一个叙事或情绪单元。
3. 每段内定韵脚位置（句尾或句中）。
4. 起草歌词，注意字数与旋律音符数的对应。
5. 检查押韵是否在预期位置。
6. 用 [lyrics-and-syllables.md](lyrics-and-syllables.md) 的逐音计划核对字与音符的对应，再用 `lyrics-check --require-full-project` 验证。

```sh
sv2cli lyrics-plan-schema
sv2cli lyrics-check song.svp --plan plan.json --require-full-project -o audit.json
```

## 逐句分工建议

长曲一次写完整歌词容易注意力涣散。推荐：

1. 按乐句切分，每句单独写一个 lyrics-plan 片段。
2. 用 [scripts/phrase_merge.py](../scripts/phrase_merge.py) 把片段合并进总计划。
3. 合并后跑 `lyrics-check --require-full-project` 验证全曲一致性。

这样每句只占用一小段上下文，合并时由脚本处理 id 重复和小节重叠检测。
